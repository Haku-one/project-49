# 🚀 Быстрый запуск WooCommerce CDEK Доставка

## За 5 минут до работы

### 1️⃣ Установка (1 минута)
```bash
# Скопируйте папку в плагины WordPress
cp -r woocommerce-cdek-delivery /wp-content/plugins/

# Или через админ-панель WordPress:
# Плагины → Добавить новый → Загрузить плагин
```

### 2️⃣ Активация (30 секунд)
- Перейдите в **Плагины** → **Установленные плагины**
- Найдите "WooCommerce CDEK Доставка"
- Нажмите **Активировать**

### 3️⃣ Настройка доставки (2 минуты)
```
WooCommerce → Настройки → Доставка → Зоны доставки
→ Выберите зону (например, "Россия")
→ Добавить способ доставки → CDEK Доставка
```

**Основные настройки:**
```
✅ Включить доставку CDEK
📝 Название: CDEK Доставка
🔑 ID аккаунта: Lr7x5fauu0eOXDA4hlK04HiMUpqHgzzR
🔒 Пароль: fzwKqoaKaTrwRjxVhf6csNzTefyHRHYM
🏙️ Город отправителя: 393 (Саратов)
```

### 4️⃣ Настройка товаров (1 минута)
Для каждого товара укажите:
```
📦 Вес: 100 г
📏 Размеры: 10×10×10 см
```

### 5️⃣ Проверка (30 секунд)
- Перейдите на страницу **Оформление заказа**
- Добавьте товар в корзину
- Выберите способ доставки **CDEK**
- Должна появиться карта с пунктами выдачи

## 🎯 Для блочного checkout

### Включение блоков (дополнительно)
```
Внешний вид → Редактор тем → Оформление заказа
→ Удалить [woocommerce_checkout]
→ Добавить блок "Оформление заказа WooCommerce"
```

## ✅ Готово!

Теперь ваши покупатели могут:
- 🗺️ Выбирать пункты выдачи на карте
- 💰 Видеть точную стоимость доставки
- 📱 Пользоваться на мобильных устройствах

## 🚨 Если что-то не работает

### Быстрая диагностика
```php
// Добавьте в wp-config.php
define('WP_DEBUG', true);
```

Затем: **WooCommerce → Тест CDEK**

### Частые проблемы
- **Не загружается карта** → Проверьте HTTPS
- **Нет пунктов выдачи** → Проверьте API ключи
- **Не рассчитывается стоимость** → Укажите вес товаров
