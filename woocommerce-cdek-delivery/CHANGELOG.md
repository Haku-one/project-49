# История изменений WooCommerce CDEK Доставка

## [1.1.0] - 2024-01-01

### ✨ Новые возможности

#### Поддержка блочного оформления заказов WooCommerce
- **Автоматическое обнаружение** блочного checkout на странице
- **Класс WC_CDEK_Blocks** для интеграции с WooCommerce Blocks API
- **REST API endpoints** для работы с блоками:
  - `POST /wp-json/cdek/v1/offices` - получение пунктов выдачи
  - `POST /wp-json/cdek/v1/calculate` - расчет стоимости доставки
- **Интеграция с Store API** для сохранения данных заказа
- **Валидация через хуки WooCommerce Blocks**

#### Полная русская локализация
- **Файл переводов** `languages/woocommerce-cdek-delivery-ru_RU.po`
- **Переведены все строки** интерфейса на русский язык
- **Обновлены** заголовки и описания плагина
- **Русские метки** для всех настроек админ-панели

#### Улучшенный пользовательский интерфейс
- **Новые стили** для блочного checkout (`assets/css/blocks.css`)
- **Адаптивный дизайн** для мобильных устройств
- **Поддержка темной темы** через CSS media queries
- **Плавные анимации** и переходы
- **Современные градиенты** и эффекты

## [1.0.0] - 2023-12-01

### ✨ Первый релиз

#### Основная функциональность
- Интеграция с CDEK API v2
- Интерактивная карта Yandex Maps
- Выбор пунктов выдачи
- Расчет стоимости доставки
- Классическое оформление заказов

#### Возможности
- Два типа доставки: самовывоз и до двери
- Автоматическое создание заказов в CDEK
- Админ-панель для управления
- Email уведомления
- Мобильная адаптация

#### Технические характеристики
- WordPress 5.0+
- WooCommerce 4.0+
- PHP 7.4+
- Yandex Maps API
- CDEK API v2
