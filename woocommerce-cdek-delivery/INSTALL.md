# Инструкция по установке и настройке WooCommerce CDEK Доставка

## 🚀 Быстрая установка

### 1. Загрузка плагина
1. Скопируйте папку `woocommerce-cdek-delivery` в `/wp-content/plugins/`
2. Перейдите в **Плагины** → **Установленные плагины**
3. Найдите "WooCommerce CDEK Доставка" и нажмите **Активировать**

### 2. Базовая настройка
1. Перейдите в **WooCommerce** → **Настройки** → **Доставка**
2. Выберите зону доставки (например, "Россия")
3. Нажмите **Добавить способ доставки**
4. Выберите **CDEK Доставка**
5. Настройте параметры:

```
Включить доставку CDEK: ✓
Название: CDEK Доставка
ID аккаунта: Lr7x5fauu0eOXDA4hlK04HiMUpqHgzzR
Безопасный пароль: fzwKqoaKaTrwRjxVhf6csNzTefyHRHYM
Код города отправителя: 393 (Саратов)
Тестовый режим: ✗ (отключить для продакшена)
Пункты выдачи: ✓
Доставка до двери: ✓
```

## 🛒 Настройка для блочного оформления заказов

### Включение блочного checkout (рекомендуется)

1. **Проверьте версию WooCommerce**
   - Минимальная версия: 8.0+
   - Рекомендуемая: 8.4+

2. **Настройте страницу оформления заказа**
   ```
   Внешний вид → Редактор тем → Страницы → Оформление заказа
   ```
   
3. **Замените содержимое на блок**
   - Удалите шорткод `[woocommerce_checkout]`
   - Добавьте блок "Оформление заказа WooCommerce"

4. **Проверьте работу**
   - Блок карты CDEK появится автоматически
   - При выборе способа доставки CDEK

### Настройка классического checkout

Если используете классическое оформление:
- Плагин работает автоматически
- Никаких дополнительных настроек не требуется

## 📦 Настройка товаров

### Обязательные параметры для расчета доставки

Для каждого товара укажите:

1. **Вес товара**
   ```
   Данные товара → Доставка → Вес: 100 (в граммах)
   ```

2. **Размеры товара**
   ```
   Данные товара → Доставка → Размеры:
   Длина: 10 см
   Ширина: 10 см  
   Высота: 10 см
   ```

3. **Управление запасами**
   ```
   Данные товара → Запасы → Отслеживать количество: ✓
   ```

## 🚨 Решение проблем

### Не отображается карта

**Проблема**: Карта не загружается на странице checkout

**Решение**:
1. Проверьте консоль браузера (F12)
2. Убедитесь что сайт работает по HTTPS
3. Проверьте API ключ Yandex Maps
4. Очистите кэш браузера

### Не работает выбор пунктов выдачи

**Проблема**: При клике на пункт выдачи ничего не происходит

**Решение**:
1. Проверьте что JavaScript не заблокирован
2. Убедитесь что нет конфликтов с другими плагинами
3. Проверьте консоль на ошибки JavaScript

### Не рассчитывается стоимость доставки

**Проблема**: Стоимость доставки показывается как 0 или не показывается

**Решение**:
1. Проверьте настройки CDEK API
2. Убедитесь что у товаров указан вес и размеры
3. Проверьте код города отправителя (393 для Саратова)
4. Включите режим отладки и проверьте логи

### Ошибки API CDEK

**Проблема**: Ошибки при обращении к API CDEK

**Решение**:
1. Проверьте правильность логина и пароля
2. Убедитесь что аккаунт CDEK активен
3. Проверьте лимиты API запросов
4. Попробуйте включить тестовый режим

### Блочное оформление не работает

**Проблема**: Карта CDEK не появляется в блочном checkout

**Решение**:
1. Обновите WooCommerce до версии 8.0+
2. Убедитесь что используется блок "Оформление заказа WooCommerce"
3. Очистите кэш плагинов
4. Проверьте что плагин активен

## 🔄 Обновление плагина

### Резервное копирование

Перед обновлением:
1. Сделайте резервную копию сайта
2. Сохраните настройки плагина
3. Проверьте совместимость с текущей версией WooCommerce

### Процесс обновления

1. Деактивируйте старую версию плагина
2. Удалите папку старого плагина
3. Загрузите новую версию
4. Активируйте плагин
5. Проверьте настройки

### После обновления

1. Проверьте работу на тестовой странице
2. Протестируйте оформление заказа
3. Убедитесь что карта загружается
4. Проверьте расчет стоимости доставки
