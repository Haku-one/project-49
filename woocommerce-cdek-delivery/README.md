# WooCommerce CDEK Доставка

Полнофункциональный плагин интеграции службы доставки CDEK для WooCommerce с интерактивной картой, выбором пунктов выдачи и автоматическим расчетом стоимости доставки. Поддерживает как классическое, так и **новое блочное оформление заказов** WooCommerce.

## 💻 Использование

### Блочное оформление заказов

1. Покупатель выбирает способ доставки **CDEK**
2. Автоматически появляется блок с картой CDEK
3. При выборе самовывоза:
   - Поле поиска города (автозаполнение из адреса)
   - Интерактивная карта с пунктами выдачи
   - Список доступных пунктов выдачи
4. Покупатель выбирает удобный пункт выдачи
5. Данные сохраняются через Store API

### Классическое оформление

1. Покупатель выбирает способ доставки **CDEK**
2. При выборе самовывоза появляется:
   - Поле поиска города
   - Интерактивная карта с пунктами выдачи
   - Список доступных пунктов выдачи
3. Покупатель выбирает удобный пункт выдачи
4. Автоматически рассчитывается стоимость и время доставки

### В админ-панели

#### Управление заказами
- **WooCommerce → Заказы** - колонка "CDEK Status" показывает статус
- В карточке заказа есть метабокс "CDEK Delivery" для:
  - Создания заказа в CDEK
  - Обновления статуса доставки
  - Просмотра данных пункта выдачи

#### Настройки и статистика
- **WooCommerce → CDEK Delivery** - главная страница с:
  - Тестом соединения с API
  - Статистикой заказов
  - Синхронизацией пунктов выдачи
  - Списком последних заказов

## 🔍 Функционал API

### REST API для блочного checkout
- `POST /wp-json/cdek/v1/offices` - получение пунктов выдачи
- `POST /wp-json/cdek/v1/calculate` - расчет стоимости доставки

### Автоматический расчет стоимости
- По весу товаров из корзины
- По размерам товаров
- С учетом города получателя
- Отображение сроков доставки

### Создание заказов
- Автоматическое создание при смене статуса на "В обработке"
- Ручное создание из админ-панели
- Передача всех данных получателя
- Сохранение UUID заказа CDEK

### Типы доставки
- **Самовывоз** (тариф 136) - до пункта выдачи
- **До двери** (тариф 233) - курьерская доставка

### База данных
Плагин создает таблицу `wp_cdek_offices` для кэширования пунктов выдачи.

### AJAX хуки (классический checkout)
- `cdek_calculate_delivery` - расчет стоимости
- `cdek_get_offices` - получение пунктов выдачи
- `cdek_create_order` - создание заказа
- `cdek_get_order_status` - получение статуса

### WooCommerce Blocks интеграция
- `WC_CDEK_Blocks` - основной класс интеграции
- `WC_CDEK_Checkout_Block_Integration` - интеграция с блочным checkout
- Store API hooks для сохранения данных

## 🚨 Устранение проблем

### Не загружается карта
1. Проверьте API ключ Yandex Maps
2. Убедитесь что сайт доступен по HTTPS
3. Проверьте консоль браузера на ошибки

### Не работает блочное оформление
1. Убедитесь что используете WooCommerce 8.0+
2. Проверьте что включен блочный checkout
3. Очистите кэш плагинов и браузера

### Не рассчитывается стоимость
1. Проверьте настройки CDEK API
2. Убедитесь что указан вес и размеры товаров
3. Проверьте код города отправителя

### Ошибки API
1. Перейдите в **WooCommerce → CDEK Delivery**
2. Нажмите "Тест соединения"
3. Проверьте правильность API ключей
