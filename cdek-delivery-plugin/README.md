# CDEK Доставка для WooCommerce

Полноценный плагин интеграции службы доставки CDEK для WooCommerce с поддержкой блочного и классического оформления заказов.

## 🚀 Возможности

- ✅ **Реальное API CDEK** - работа с официальным API v2
- ✅ **Блочный checkout** - поддержка нового блочного оформления WooCommerce
- ✅ **Классический checkout** - совместимость со старым checkout
- ✅ **Интерактивная карта** - Yandex Maps с пунктами выдачи
- ✅ **Автоматический расчет** - стоимость доставки через API
- ✅ **Кэширование** - быстрая загрузка данных
- ✅ **Русский интерфейс** - полная локализация
- ✅ **Адаптивный дизайн** - работает на всех устройствах
- ✅ **Админ панель** - просмотр данных заказов

## 📦 Установка

### 1. Загрузка плагина

1. Скачайте папку `cdek-delivery-plugin`
2. Загрузите её в `/wp-content/plugins/`
3. Переименуйте в `cdek-delivery`

### 2. Активация

1. Перейдите в **WP Admin → Плагины**
2. Найдите **"CDEK Доставка"**
3. Нажмите **"Активировать"**

### 3. Настройка

1. Перейдите в **WooCommerce → Настройки → Доставка**
2. Выберите зону доставки или создайте новую
3. Добавьте метод **"CDEK Доставка"**
4. Настройте параметры:

```
✅ Включить: Да
📝 Название: CDEK Доставка  
💰 Фиксированная стоимость: 300 руб
🔑 Client ID CDEK: ваш_client_id
🔐 Client Secret CDEK: ваш_client_secret
🏙️ Город отправки: 44 (код Москвы)
⚖️ Вес по умолчанию: 1 кг
🆓 Бесплатная доставка от: 0 (отключить)
```

## 🔑 Получение API ключей CDEK

1. Перейдите на [lk.cdek.ru](https://lk.cdek.ru)
2. Зарегистрируйтесь или войдите
3. Перейдите в **Интеграция → API**
4. Создайте новое приложение
5. Скопируйте **Client ID** и **Client Secret**

## 🛠️ Настройка WooCommerce

### Для блочного checkout:

1. **Внешний вид → Редактор тем → Оформление заказа**
2. Убедитесь что используется блок **"Оформление заказа WooCommerce"**
3. Сохраните изменения

### Для классического checkout:

1. **Внешний вид → Редактор тем → Оформление заказа**
2. Используйте шорткод: `[woocommerce_checkout]`
3. Сохраните изменения

## 📋 Как это работает

### 1. Покупатель выбирает CDEK доставку
- На странице checkout появляется блок выбора пункта выдачи
- Автоматически подставляется город из адреса доставки

### 2. Поиск пунктов выдачи
- Введите город или используйте автозаполнение
- Нажмите "Поиск"
- Загружаются реальные пункты выдачи CDEK

### 3. Выбор на карте или в списке
- Интерактивная Yandex карта с метками
- Список пунктов с адресами и временем работы
- Клик по пункту для выбора

### 4. Оформление заказа
- Выбранный пункт сохраняется в заказе
- Рассчитывается стоимость доставки
- Данные передаются в админ панель

## 🔧 Отладка

### Проверка работы:

1. **Откройте консоль браузера** (F12 → Console)
2. **Перейдите на checkout** и выберите CDEK доставку
3. **Должны появиться сообщения**:
   ```
   CDEK pickup selector added
   Initializing CDEK delivery functionality
   CDEK shipping selected: true
   ```

### Если не работает:

1. **Проверьте API ключи** - правильность Client ID и Secret
2. **Проверьте город отправки** - должен быть код CDEK
3. **Проверьте консоль** - ошибки JavaScript
4. **Проверьте логи** - `/wp-content/debug.log`

### Тестовые команды в консоли:

```javascript
// Проверить наличие AJAX объекта
console.log(cdek_delivery_ajax);

// Принудительно показать блок

    action: 'cdek_get_offices',
    city: 'Москва',
    nonce: cdek_delivery_ajax.nonce
}).done(function(response) {
    console.log('Test result:', response);
});
```

## 🐛 Известные проблемы

### Блок не появляется
- **Причина**: Конфликт с темой или другими плагинами
- **Решение**: Проверьте консоль на ошибки JavaScript

### Ошибка API
- **Причина**: Неправильные ключи или лимиты API
- **Решение**: Проверьте ключи в личном кабинете CDEK

### Не загружаются офисы
- **Причина**: Блокировка запросов или неправильный город
- **Решение**: Проверьте название города и настройки сервера
